#### A streamlit UI which allows a user to search, select, and find similar manga. The data used in processing was gathered from MyAnimeList.net, the data used holds roughly 32,000 users.
- The Jupiter notebook is solely for accruing and organizing data into datalist.json, it is not a necessary operation once it has been done once and I don't think someone wants to spend over a day collecting more user information, but if you do there is the instructions of how to do so inside of it.
- If you just want the finished product go into dist and download MyRecomender.exe
- If you don't trust me then don't do that
- made using python 3.12.9
- .exe made with streamlit 1.49.1 (specific version is only needed to make exe)
